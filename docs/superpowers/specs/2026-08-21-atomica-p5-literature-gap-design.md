# ATOMICA — P5: Literature Agent (Research-Gap Extrapolation)

- **Date:** 2026-08-21
- **Status:** Approved (design), pending implementation plan
- **Builds on:** P2/P4 (`atomica/critic_world.py` — the Cu-Au 924-config world, `build_world`,
  `features`, cached energies) and P3/P4's LLM conventions (strict-tool structured output, injected
  client, credential-gated auto-skip).
- **Roadmap position:** Phase P5 — a literature agent that reads a study and reasons about what it did
  **not** explore. The last LLM slice.
- **Spike:** the measured task below was re-derived from a throwaway spike (§9). The original framing
  (does a feature→energy *sign* reverse in the unexplored region?) was **moot on this world** — the
  spike found 0% sign reversals, so a "trend always holds" baseline scored 100%. The reframe used here
  (does the unexplored region contain a *better optimum*?) was then spike-validated: 29% base rate, a
  71% majority baseline, and a simple trend heuristic already at 86% — a real, learnable, non-trivial
  signal. All quoted rates are from that spike on the real MACE world.

---

## 1. Context

The project vision (plan §7) asks the literature agent not "what did this paper say?" but "what did
this paper **not** explore?" — identify the research gap, then hypothesize about it. The measured,
cheat-proof question (plan line 27):

> Can an AI read a study and produce a hypothesis about the unexplored region that is **not stated in
> the study** and turns out to be **true** against ground truth — better than a paper-blind baseline?

As in every prior slice, the LLM never touches the physics. A synthetic "paper" reports real findings
over an explored subset of a design space we have full ground truth for; the LLM reads only that
summary and predicts a property of the unexplored region; the harness checks it against the full 924.

## 2. The measurable claim

The world is the **P4/P2 Cu-Au 12-site FCC lattice** (6 Au / 6 Cu, C(12,6)=924 orderings, exact MACE
energy each, already cached by `critic_world.build_world`). The **global minimum** is known
(−44.3685 eV). A synthetic "paper" studies an **explored subset** of the design space — the orderings
whose value on one structural feature `Z` falls in a band — and reports its findings (§3). The
**unexplored gap** is the complement.

The agent reads the paper and predicts one bit:

> **Does the unexplored gap contain a structure with lower energy than the paper's best?**

This is exactly equivalent to "is the global minimum in the gap?" (the gap's best beats the explored
best iff the global minimum lies outside the explored subset), so it is labeled TRUE/FALSE against
ground truth with no ambiguity.

Three arms predict this bit over **N papers** (default 60, `--n-papers`):

- **baseline** — a paper-blind constant: always predict FALSE ("the study already covered the best
  region"). Its accuracy is the majority-class rate (~71% in the spike). This is the honest, strong bar
  the LLM must beat to have added anything.
- **heuristic** — a non-LLM reference that reads the paper's reported boundary trend: if the best
  energy improves toward the gap side, predict TRUE. The spike put this at ~86% — a reference *ceiling*
  showing the signal is real and readable, **not** a bar the LLM must clear.
- **llm** — the LLM reads the paper summary and predicts the bit.

> **Headline:** does the paper-reading LLM's accuracy beat the paper-blind **baseline** (and how close
> does it get to the **heuristic** ceiling)? LLM ≈ baseline ⇒ the LLM adds nothing (a valid, honestly
> reported negative, as in every prior slice). LLM worse than the always-FALSE constant is also
> possible and would be reported as-is.

## 3. The world, the paper, and the ground truth

All statistics operate on the **table** already built by `critic_world.build_world` (924 configs, the
three P4 features `x1`/`x2`/`layer`, and the MACE energy). No P2/P3/P4 file is modified — P5 imports
and reuses them.

**A paper** (deterministic, seeded) is generated by:

1. Pick a **split feature** `Z` (one of `x1`/`x2`/`layer`) and a **value band** on `Z` (a low/high
   quantile pair), sampled so the explored subset is a non-trivial fraction of the 924 (target
   explored fraction in ~[0.3, 0.7]); the **explored** subset = configs whose `Z` is in the band, the
   **gap** = the complement.
2. Compute the paper's reported findings **from the explored subset only**:
   - `axis` = `Z`; a human-readable `region` description (e.g. "orderings with x2 in the low range");
     `n_explored`;
   - `best_config` + `best_energy` = the minimum-energy ordering within the explored subset;
   - `boundary_trend` = the best (min) energy in each of ~3–4 ordered sub-bands of `Z` **within the
     explored subset**, ordered from farthest to nearest the gap boundary — the signal a reader would
     use to judge whether energy is still improving where the study stopped.
3. The **ground-truth label** `better_in_gap` (bool) = does any config in the gap have energy below
   `best_energy` (⟺ the global minimum is in the gap). **Computed by the harness, never shown to any
   arm.**

Papers are generated over seeds, skipping degenerate ones (explored or gap too small, or a tie at the
boundary), until N valid papers with a **non-trivial class mix** are collected (implementation asserts
the base rate lands in a sane range, ~[0.2, 0.5], echoing the spike's 29%).

## 4. The agent and the cheat-proof boundary

**What each arm sees:** the paper summary from §3 — `axis`, `region`, `n_explored`, `best_config`,
`best_energy`, `boundary_trend`, and which side the gap is on. It does **not** see any gap config, the
gap's energies, the global minimum, or the label. The only path to the truth is reasoning about the
reported trend — exactly the "hypothesis not stated in the paper" the vision asks for.

**LLM action space (strict structured output, P3/P4 style):** a single strict tool `predict_gap`
returning `{better_in_gap: boolean}`. Every output is validated; an unparseable/invalid output falls
back to FALSE (recorded `fallback: true`). The LLM output is parsed as data, never executed.

**The heuristic** (`heuristic` arm) is a deterministic reference over the same `boundary_trend`: if the
per-sub-band best energy is still decreasing at the sub-band nearest the gap boundary (energy improving
where the study stopped), predict TRUE, else FALSE. It uses the identical information handed to the
LLM, so "LLM ≈ heuristic" means the LLM reads the reported signal as well as the explicit rule does.

## 5. Arms, metrics, and fairness

For a batch of N papers (mixed TRUE/FALSE by §3), each arm predicts `better_in_gap`; the harness scores
against the label:

- **accuracy** = correct / N — **primary**.
- **precision** and **recall** on the TRUE class (gap-has-a-better-structure) — the actionable minority;
  reported so a "always FALSE" arm's 0 recall is visible.
- (Reported alongside: the base rate, and each arm's accuracy, so baseline≈majority and
  heuristic≈ceiling are both legible.)

**Fairness invariant:** all three arms see the identical paper summaries and the identical N-paper
batch; only the prediction rule differs. No arm sees the gap data, the global minimum, or the label.
This is P3/P4's fairness discipline restated for the reviewer.

## 6. Safety & the LLM boundary (inherited from P3/P4)

- The LLM's entire action space is **one boolean**, returned as validated strict-tool JSON. It cannot
  emit or run code, choose the physics, or see the ground truth.
- Every output passes harness validation; invalid → FALSE fallback (`fallback: true`).
- **Credentials are the user's:** the SDK reads `ANTHROPIC_API_KEY` or an `ant auth login` profile; no
  key in code. If no credential is configured, the **llm arm auto-skips** (as P4's `run_critic` does)
  and the baseline/heuristic arms still run. **Tests never hit MACE or the real API** — a synthetic
  world (fake `evaluate_fn`) and a fake/injected client.
- **Model:** default `claude-sonnet-5` (module constant `MODEL`, switchable via `--model`).
- Reproducibility via `numpy.random.default_rng(seed)` for paper generation; the LLM arm is inherently
  stochastic (reported as a caveat).

## 7. Architecture

Two new modules (world/reviewer seam) plus a CLI. Reuses `critic_world` (hence `alloy`) unchanged.

- `atomica/litreview_world.py` — paper generation + ground truth, decoupled from MACE:
  - reuses `critic_world.build_world(evaluate_fn, cache_path)` for the table (tests inject a fake
    `evaluate_fn`; only the deliverable builds the real 924).
  - `make_paper(world, seed, min_frac=0.3, max_frac=0.7) -> paper` — deterministic seeded paper +
    label. `paper` dict: `axis`, `region`, `n_explored`, `best_config`, `best_energy`,
    `boundary_trend` (list of floats, far→near the gap), `gap_side`, and (top-level, for scoring only,
    never in the prompt) `better_in_gap`.
  - `generate_papers(world, n_papers, seed0=0, ...) -> list[paper]` — N valid, non-degenerate papers.
- `atomica/litreview.py` — the reviewers and scoring:
  - `PREDICT_TOOL` (strict schema `{better_in_gap: boolean}`), `validate_prediction(raw) -> {"better_in_gap": bool}`.
  - `baseline_reviewer(paper) -> {"better_in_gap": False}`; `heuristic_reviewer(paper) -> {...}`;
    `llm_reviewer(client, model=MODEL)`; `build_prompt(paper)`.
  - `review_one(paper, reviewer)`, `review_batch(papers, reviewer)`,
    `score(papers, predictions) -> {accuracy, precision, recall, n, base_rate_better}`; `MODEL`.
- `atomica/run_litreview.py` — CLI: build/load world, generate N papers, run baseline+heuristic always
  and llm if a client is available, score, write `results/litreview_report.json` (`arms` = {name:
  score_dict}, `config`). `make_llm_reviewer(model)` returns None (arm auto-skips) if no credential/SDK;
  the LLM-arm call is guarded for lazy-auth like P4's `run_critic`.

### Data flow

```
build_world (MACE, cached) ─▶ generate_papers × N (deterministic, labeled, summary-only)
   papers ──▶ baseline_reviewer   ┐
         ──▶ heuristic_reviewer  ┤─ review_batch ─▶ predictions ─▶ score (accuracy/precision/recall)
         ──▶ llm_reviewer        ┘                                        │
   per-arm scores ──▶ results/litreview_report.json + table
```

## 8. Testing & validation

Tests must be **fast** and **never** hit MACE or the Anthropic API:

- **Paper generation on a synthetic table:** feed `build_world` a fake `evaluate_fn` with a *known*
  structure; assert `make_paper` reports the correct explored best, that `boundary_trend` is computed
  from the explored subset only, and that `better_in_gap` matches an independent recomputation. Assert
  `generate_papers` produces both TRUE and FALSE labels across seeds.
- **Cheat-proof (key):** assert `build_prompt(paper)` does **not** contain the label or any gap-only
  quantity, and is a pure function of the summary fields (two papers differing only in `better_in_gap`
  produce identical prompts).
- **Heuristic:** on a hand-built paper whose `boundary_trend` is still improving at the boundary,
  `heuristic_reviewer` predicts TRUE; on a flat/worsening trend, FALSE.
- **Validation:** `validate_prediction` accepts a well-formed bool, rejects/faults garbage → FALSE
  fallback.
- **Baseline** always predicts FALSE; **score** returns correct accuracy/precision/recall on a
  hand-built set (including the degenerate all-FALSE case → recall 0, no divide-by-zero).
- **LLM reviewer** with a **fake client** returns the injected `tool_use` bool; `build_prompt` mentions
  the region and the boundary trend. No network, no key.
- **CLI smoke** (monkeypatch `make_llm_reviewer → None` and `build_world → fake`): runs
  baseline+heuristic, writes a report with both arms and no `llm` arm.
- The real `llm_reviewer` runs only in the credential-gated deliverable.

## 9. Deliverable / honest caveats

Deliverable: `results/litreview_report.json` + a README "P5" section answering — on N papers — does the
paper-reading LLM's accuracy beat the paper-blind **baseline** (~71%), and how close to the
**heuristic** ceiling (~86%)?

Honest caveats to report as-is:
- The LLM is **stochastic**; report one batch as one sample (optionally a couple of seeds).
- The **baseline is the majority class** (~71%): beating it is the real bar, and the LLM *can* score
  below the always-FALSE constant — that would be reported plainly.
- The task is a **single bit** on a **small 12-site, fixed-composition world** with an injected
  (synthetic) paper; it is a controlled benchmark of gap-extrapolation reasoning, not a claim about
  reading real literature. The original sign-reversal framing was moot here (§Spike) — the reframe is
  what the world supports.
- A null result (LLM ≈ baseline) is a result.

## 10. Dependencies & scope

- No new dependency (`anthropic` already present). Credential is the user's; never committed.
- **In scope:** paper generation + ground-truth labeling, the three reviewers (baseline, heuristic,
  LLM), batch scoring, a CLI, tests with a synthetic world + fake client, one credential-gated
  deliverable run.
- **Out of scope (later phases):** predicting *where* in the gap the optimum lies (P5 keeps a single
  bit — the location variant is deferred); real paper/PDF/arXiv ingestion (no ground truth); a
  composition/temperature design axis; feeding the hypothesis into an automated P3 search loop; any
  world beyond the P4 Cu-Au lattice.
